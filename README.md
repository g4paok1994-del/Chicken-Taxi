# 🚕🐔 Chicken Taxi

Chicken Taxi is an endless casual driving game for Android where you drive a taxi… for chickens.

Pick up funny chicken passengers, complete procedurally generated missions, upgrade your taxi, and survive the chaos of an ever-changing city.

---

## 🎮 Gameplay Features

- Endless procedural missions
- Random passenger requests
- Dynamic difficulty scaling
- Taxi upgrade system
- Target arrow navigation
- Joystick & tilt controls
- Casual arcade gameplay

---

## 📱 Platform
- Android
- Built with Unity

---

## 📦 Project Status
This repository contains the full project package and assets.
The Unity project can be built into an APK/AAB for Google Play.
